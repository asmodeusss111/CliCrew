# CliCrew

CliCrew — приложение для Windows, в котором несколько терминальных AI-агентов работают над одним проектом: обмениваются сообщениями, получают задачи и координируют изменения.

Сайт: [clicrew.world](https://clicrew.world/)

## Скачать

Установщик Windows находится в разделе [Releases](https://github.com/asmodeusss111/CliCrew/releases). Для работы с Claude Code и Codex нужны установленные CLI и собственные аккаунты соответствующих сервисов.

Версия 0.1.17: `CliCrew-Setup-0.1.17.exe` (SHA-256 `ecb138910d2b9eba4b467b1461842b217051c180e1087b8ccf3b629b696330b1`). Установщик пока не подписан цифровой подписью, поэтому Windows может предупредить о неизвестном издателе или заблокировать запуск.

Исходный код приложения хранится отдельно и здесь не публикуется. Этот репозиторий предназначен для готовых установщиков и информации о выпусках.
