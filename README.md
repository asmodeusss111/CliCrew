# CliCrew

CliCrew — приложение для работы нескольких CLI-агентов над одним проектом. Claude Code, Codex и другие агенты общаются через локальный хаб и делят между собой задачи.

Сайт: [clicrew.world](https://clicrew.world/)

[Проекты сообщества](https://clicrew.world/#gallery) · [Доска развития](https://clicrew.world/#roadmap) · [Как предложить проект или функцию](COMMUNITY.md)

## Скачать

Установщик Windows: [CliCrew 0.1.29](https://github.com/asmodeusss111/CliCrew/releases/tag/v0.1.29). Для работы нужны установленные CLI и аккаунты соответствующих сервисов.

Проверочная сумма установщика (SHA-256): `6ae9b9fb5ef7ca7409215bd0a77abd9fec98964f3c3baa8d49d3fbd1902f4ef2`.

Сейчас CliCrew бесплатный. [Условия использования](https://clicrew.world/terms.html). Установщик пока без цифровой подписи, поэтому Windows может показать предупреждение или заблокировать его. Исходный код не публикуется; этот репозиторий предназначен для релизов.

## История изменений

- [0.1.29 — визуальные правки превью, управляющий и инструменты проекта](https://github.com/asmodeusss111/CliCrew/releases/tag/v0.1.29).

- [0.1.28 — история, репозитории, SSH-превью и файлы, базы данных и окружения](https://github.com/asmodeusss111/CliCrew/releases/tag/v0.1.28).
- [0.1.27 — SSH-проекты, библиотека проектов и раскладки](https://github.com/asmodeusss111/CliCrew/releases/tag/v0.1.27).

- [0.1.24 — новые карточки агентов и MCP](https://github.com/asmodeusss111/CliCrew/releases/tag/v0.1.24).
- [0.1.22 — каталог, избранное и папки скиллов](https://github.com/asmodeusss111/CliCrew/releases/tag/v0.1.22).
- [0.1.21 — скиллы из GitHub и лаборатория](https://github.com/asmodeusss111/CliCrew/releases/tag/v0.1.21).
- [0.1.20 — отчёт о лаборатории проекта](https://github.com/asmodeusss111/CliCrew/releases/tag/v0.1.20).
- [0.1.19 — отчёт о добровольной статистике](https://github.com/asmodeusss111/CliCrew/releases/tag/v0.1.19).

0.1.19 и 0.1.20 опубликованы как архивные отчёты без отдельных установщиков; их изменения входят в 0.1.21. Импорт скиллов не запускает файлы и не гарантирует безопасность инструкций.

Каталог и избранное в приложении требуют доступного обновлённого сервера сайта. Публикация 0.1.22 не подтверждает восстановление хостинга. Импорт всегда требует просмотра и подтверждения; агенты автоматически не запускаются.

0.1.24 включает новые карточки настроек и MCP-серверы из исходной 0.1.23. Карточки и локальный MCP не требуют сервера сайта. Настройки и назначения применяются при следующем запуске агента; просмотр не запускает серверы и инструменты.

0.1.27 добавляет удалённые проекты через SSH: Linux x64, glibc 2.35+, Node.js 24+, npm и OpenSSH/SFTP. CLI устанавливаются и авторизуются на сервере. Микрофон и пульт телефона в установщик не входят. Этапы 0.1.25 и 0.1.26 не стали отдельными принятыми публичными установщиками; готовые изменения без отложенных функций вошли в 0.1.27.

0.1.28 добавляет поиск локальной истории, рабочие пространства до восьми репозиториев с сохранением сессий, SSH-превью, SFTP с просмотром перед заменой, SQLite/PostgreSQL и сравнение окружений без чтения содержимого .env. Базы по умолчанию доступны для чтения; запись требует отдельных подтверждений. Микрофон и телефонный пульт по-прежнему исключены. Владелец подтвердил установку и запуск этого выпуска; подробные проверки и ограничения — в отчёте релиза.


0.1.29 добавляет визуальное поручение по выбранному элементу локального превью и настоящие снимки до/после, управляющего с подтверждаемым планом, переход из сообщений в исходники, карту ошибок, HTTP API-клиент, сервисы и редактируемый пакет передачи работы агенту. Микрофон и пульт телефона исключены. Финальный EXE прошёл установку и запуск в чистой Windows CI; в проверках использовались Node-исполнители без платных моделей. Визуальные поручения пока не поддерживают SSH. Полный отчёт и контрольная сумма приложены к выпуску.
