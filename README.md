# CliCrew

CliCrew — приложение для работы нескольких CLI-агентов над одним проектом. Claude Code, Codex и другие агенты общаются через локальный хаб и делят между собой задачи.

Сайт: [clicrew.world](https://clicrew.world/)

## Скачать

Установщик Windows: [CliCrew 0.1.17](https://github.com/asmodeusss111/CliCrew/releases/tag/v0.1.17). Для работы нужны установленные CLI и аккаунты соответствующих сервисов.

Проверочная сумма установщика (SHA-256): `ecb138910d2b9eba4b467b1461842b217051c180e1087b8ccf3b629b696330b1`.

Сейчас CliCrew бесплатный. Установщик пока без цифровой подписи, поэтому Windows может показать предупреждение или заблокировать его. Исходный код не публикуется; этот репозиторий предназначен для релизов.
